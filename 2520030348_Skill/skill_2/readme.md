2.	To Create Main Loop, Display Prompt, Read User Input, Handle Exit Conditions, Design Control Flow Diagram, Test Interactive Loop

This experiment focuses on taking keyboard input and processing it in a simple Linux program.
The program stores each typed character in an **input buffer**.
When the user presses **Backspace**, the last character is removed from the buffer.
When **Enter** is pressed, the entered command is processed and the buffer is cleared.
The program supports **multi-character commands** such as `hello` or `exit`.
This helps us understand how keyboard input and basic user interaction are handled in a Linux program.
