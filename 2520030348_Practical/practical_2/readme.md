2.	Develop a C program that uses the system calls open(), read(), write(), and close() to copy the contents of one file to another. Explain how control transitions between user space and kernel space during execution.

Use the strace utility to trace all system calls generated by the command cat sample.txt. Analyze the sequence of system calls and identify the kernel services involved.


During execution, a program normally runs in **user space**, where it has limited access to system resources.
When it needs a service such as reading a file, it makes a **system call**, which transfers control to **kernel space**.
The kernel performs the requested operation and then returns the result back to the program in user space.
Using `strace cat sample.txt`, we can observe system calls such as `open()`, `read()`, `write()`, and `close()`.
These calls show how `cat` asks the kernel to open the file, read its contents, display them, and finally close the file.
Thus, `strace` helps us understand the interaction between a user program and the kernel.
